How counting works

Service events are aggregate counters. Identified-agent metrics use a client-generated pseudonymous identifier; the service stores only a one-way hash for counting active and returning agents. IP addresses are not used to manufacture an agent count. Monitoring and synthetic smoke-test traffic are excluded where supported.
