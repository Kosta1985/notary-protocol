Evidence, not judgment

Record once.
Verify anywhere.

AccordTrace binds evidence to a service-recorded time and signs the result. It never decides whether the underlying action was true, legal or commercially good.

  1. 01Record

    Send the agent event or handoff data you want to make tamper-evident.

  2. 02Canonicalize

    AccordTrace normalizes JSON and computes a stable SHA-256 digest.

  3. 03Attest

    The service signs the evidence record and returns a proof ID.

  4. 04Verify

    Any later system can check the proof through REST, MCP, A2A or the web.
