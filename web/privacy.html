Privacy · Public beta

Minimal measurement.

The application records aggregate daily event counts to understand whether the protocol is useful. It does not create user profiles.

Stored telemetry

Daily totals for page views, demo loads, verification attempts, valid and invalid results, A2A calls, receipt retrievals, pilot page views, and pilot request clicks.

Not stored by the application

No cookie identifiers, IP addresses, user-agent strings, fingerprints, account identifiers, or envelope contents are added to the analytics database.

Protocol evidence

When you submit a DealEnvelope, the service stores the signed NotaryReceipt so it can be retrieved by its receipt ID. The receipt contains the submitted evidence digest, verification checks, deal ID, timestamp, notary public key, and signature.

Public statistics

Aggregate 30-day activity is available at /v1/stats.
