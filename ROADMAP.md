# Roadmap

## 0.1 public beta

- Gather feedback on DealEnvelope and NotaryReceipt semantics.
- Publish interoperability test vectors.
- Validate Node and Cloudflare runtime parity.
- Package the MCP adapter for the official registry.
- Exercise the A2A adapter against current compatibility tooling.

## 0.2 candidate

- Resolve extension and version-negotiation rules.
- Add key identifiers and rotation guidance.
- Define replay and retention profiles.
- Add conformance fixtures for additional languages.
- Complete an external security review.

## 1.0

- Freeze the core evidence model and signature domains.
- Publish a formal conformance suite.
- Document stable compatibility and deprecation policy.

This roadmap is directional. Security and interoperability findings take priority over dates.
