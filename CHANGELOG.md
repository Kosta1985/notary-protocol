# Changelog

## 0.1.0 · 2026-08-24

Initial public beta.

- Draft DealEnvelope and NotaryReceipt schemas and specification.
- Domain-separated Ed25519 verification with RFC 8785 canonical JSON.
- Signed positive and negative receipts with 16 explicit checks.
- Public verifier, REST API, durable Cloudflare D1 deployment and local Node runtime.
- TypeScript and Python SDKs, MCP stdio package and A2A 0.3 compatibility adapter.
- Anonymous aggregate activity dashboard and privacy disclosure.
- Public conformance vectors, examples, OpenAPI and agent-readable discovery files.

The 0.1 protocol remains a draft. Compatibility may change based on security and interoperability review.
