# AccordTrace AAIF readiness

AccordTrace is being prepared for a future Agentic AI Foundation (AAIF) project submission. The objective is to meet the foundation's published expectations before submitting rather than treating the intake form as a marketing channel.

## Why AccordTrace fits

AccordTrace improves interoperability, governance, reliability, observability and developer workflows for agentic systems by providing portable, tamper-evident receipts for agent actions, artifacts, approvals and workflow handoffs.

It is protocol-agnostic at the evidence layer and currently exposes MCP, A2A, REST and OpenAPI interfaces.

## Readiness gaps to close before submission

1. **Community depth** — obtain independent contributors, framework integrations or reproducible third-party interoperability tests.
2. **Adoption evidence** — publish real usage metrics without inflating registry suggestions into user counts.
3. **Governance** — add CONTRIBUTING, CODE_OF_CONDUCT, SECURITY and clear maintainer/release policies if any are missing or incomplete.
4. **Security posture** — document threat model, abuse boundaries, disclosure path and release integrity.
5. **Roadmap** — maintain a public 6–12 month roadmap with concrete technical milestones and community goals.
6. **Release quality** — keep MCP metadata, A2A Agent Card, OpenAPI and package versions synchronized.
7. **Interoperability evidence** — preserve reproducible tests that demonstrate verification across independent clients/runtimes.

## Proposed 6–12 month roadmap

### 0–3 months

- Stabilize production deployment and public health checks.
- Complete verified/claimed discovery profiles.
- Publish framework examples for major agent runtimes.
- Obtain at least three independent interoperability reproductions.
- Improve public usage metrics and privacy-safe telemetry.
- Formalize security disclosure and contribution guidance.

### 3–6 months

- Add namespaced receipts and retention controls.
- Introduce signed export bundles and deterministic verification tooling.
- Add conformance tests for MCP and A2A paths.
- Expand SDK coverage and framework-native examples.
- Recruit outside contributors/maintainers.

### 6–12 months

- Establish open governance beyond a single maintainer.
- Publish a stable receipt schema and compatibility policy.
- Add deployment options for organizations requiring private infrastructure.
- Build a compatibility matrix across major agent frameworks.
- Evaluate AAIF project submission when adoption and governance evidence are sufficient.

## Submission rule

Do not claim AAIF affiliation, membership, endorsement or project status unless formally accepted. Until then, describe AccordTrace only as an independent open project aligned with agent interoperability and governance goals.
