# Pass the proof — organic public-beta campaign

Campaign: `handoff_beta_20260905` · Start: 5 September 2026 · Project: AccordTrace only.

## Offer and audience

**Pass the proof. Not just the claim.** Agent builders can run a free synthetic handoff test: create a record, verify the original data, change one field and require rejection. The REST starter needs no account, card or model API key. The entry page is `/start.html`; source is `examples/agent-handoff/campaign.mjs`.

Focus on developers already exchanging structured results or artifact digests between clients, MCP/A2A integrators and automation teams. Ask them to test one checkpoint, not migrate a whole system. Public beta does not provide an uptime SLA.

## Measurement and publishing ledger

- Channel links in `posts.md` contain non-personal UTM labels. UTM links alone do not measure clicks or conversions. This release does not install a channel click dashboard or change the existing waitlist's attribution.
- The starter's optional `--source` argument accepts a small fixed allowlist and stores only that label in synthetic metadata. It is self-reported, not verified channel attribution.
- `metadata.synthetic=true` separates demo runs from ordinary activity. A one-client test is not an independent two-agent report, customer, sale or payout.
- Count an independent test only with an external builder's actual client/interface details, exact-match and mutation-rejection results. Ask before quoting it as an endorsement.
- The feedback board is https://github.com/Kosta1985/notary-protocol/issues/17. It is not a census of all users.
- All social/community copy in `posts.md` is a DRAFT until a real scheduled-post record or permalink is recorded. A repository document is not evidence of social publication.
